EXECUTION DISCIPLINE (for AI coding agents)

Do not rush into implementation.

Before writing any code:

1. Analyze the requirements.
2. Identify reusable patterns.
3. Design the component hierarchy.
4. Define the design system.
5. Identify shared components.
6. Plan state management.
7. Plan folder structure.
8. Plan responsive behavior.
9. Plan accessibility.
10. Plan animations and interactions.

Only then implement the solution.

During implementation:

- Refactor whenever duplication appears.
- Prefer composition over inheritance.
- Extract reusable abstractions.
- Keep components focused and small.
- Avoid premature optimization, but never sacrifice maintainability.
- Follow DRY, KISS, SOLID, and Separation of Concerns.
- Ensure every commit-quality change could pass a senior engineer's code review.

Continuously self-review the implementation and improve it until it meets production-grade standards rather than stopping at the first working solution.
